# Indigo Collier — Digital Portfolio
**Phase 1: Digital Foundations | Persevere Coding Bootcamp | Memphis, TN**

---

## About

I am a software developer based in Memphis, Tennessee, currently building production-ready applications at Banyan Labs. This portfolio was built during Phase 1 of the Persevere Full Stack Developer Program and documents 20 days of hands-on web development work — from raw HTML through responsive design, accessibility, performance optimization, and Tailwind CSS.

Every page was hand-built, tested across browsers and screen sizes, and optimized to professional Lighthouse standards:

- **Performance:** 99–100 across all four pages
- **Accessibility:** 94–95 across all four pages
- All images compressed from ~500KB to ~100KB using Squoosh (WebP format)
- W3C validation: zero errors on all pages

## Technologies

- **HTML5** — semantic structure, ARIA labels, keyboard navigation
- **CSS3** — Flexbox, Grid, animations, CSS variables, responsive media queries
- **Tailwind CSS** — utility-first styling via CDN (Days 14–19)
- **Git** — version control with meaningful commit messages throughout
- **Chrome DevTools / Lighthouse** — responsive testing and performance auditing
